# The Black Pine

A first-person psychological survival horror game built in **Godot 4.6** and
targeting **HTML5/WebAssembly** as its primary platform — desktop browsers,
Android Chrome and iOS Safari from a single build.

> You are a forestry acoustician sent into the Black Pine Basin to service a
> network of listening posts that were decommissioned thirty years ago and
> started transmitting again last month. The basin records sound. It has been
> recording for a very long time, and it has learned to play things back.

---

## Running it

```bash
# Import assets once (first run only)
godot --headless --path . --import

# Play
godot --path .

# Run the automated test suite (exits non-zero on failure)
godot --headless --path . res://scenes/test/test_runner.tscn

# Measure procedural asset generation cost
godot --headless --path . res://scenes/test/profile_assets.tscn

# Export a web build
godot --headless --path . --export-release "Web" build/web/index.html
```

There is nothing to install beyond Godot. See [`docs/BUILD.md`](docs/BUILD.md)
for export presets and hosting requirements.

## What makes this project unusual

**Everything is generated at runtime.** There is not a single `.png`, `.ogg`,
`.wav` or `.glb` in the repository. Meshes come from
[`MeshFactory`](scripts/core/mesh_factory.gd), textures from
[`TextureFactory`](scripts/core/texture_factory.gd), and every sound in the
game — wind, rain, thunder, footsteps, whispers, wildlife, the entire adaptive
score — is synthesised by [`AudioSynth`](scripts/core/audio_synth.gd) at boot.

That is not a stunt. It is the decision that makes the rest of the brief
achievable:

| Requirement | How procedural generation serves it |
| --- | --- |
| Fast load on mobile browsers | The download is code, not assets. No texture streaming, no audio decode. |
| Commercial-use licensing | Every asset is original work generated by this repository. See [`docs/ASSET_LICENSES.md`](docs/ASSET_LICENSES.md). |
| Scaling to device performance | Mesh density and audio layer count follow the quality tier instead of being baked in. |
| A large, varied world | The basin is 1 km² of seeded terrain; the seed is 4 bytes in the save file. |

The cost is paid at boot: roughly 1.4 s of generation natively, ~4 s on a
mid-range phone, behind a progress bar on the title card. The
[`profile_assets`](scripts/test/profile_assets.gd) scene exists to keep that
number honest.

## Architecture at a glance

```
scripts/
  autoload/    singletons: Log, EventBus, Platform, Settings,
               PerformanceDirector, AssetFoundry, AudioDirector,
               SaveManager, GameState, SceneRouter
  core/        pure factories with no scene-tree dependencies
  world/       terrain generation, chunk streaming, time, weather
  player/      controller, camera, interaction, survival stats
  ai/          perception, steering, enemy and wildlife behaviour
  items/       item database, inventory model
  ui/          menus, HUD, inventory UI, touch controls
  story/       objectives, documents, endings
  test/        test framework and profiling harnesses
shaders/       terrain, vegetation, water, sky, fog, rain, post-process
scenes/        thin scene files; dynamic content is built in code
tests/         test cases discovered by the runner
docs/          design and systems documentation
```

Systems never hold cross-layer references. They publish to
[`EventBus`](scripts/autoload/event_bus.gd) and read from
[`GameState`](scripts/autoload/game_state.gd). That is what lets the streaming
world create and destroy nodes freely, and what makes every subsystem testable
headlessly.

Full detail: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
